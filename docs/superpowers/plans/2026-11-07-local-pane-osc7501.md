# local pane OSC 7501 연결 구현 계획

**목표:** Claude에서 ESC로 turn을 취소하면 local pane의 THINK bar가 멈추게 한다. local pane이 OSC 7501 질의에
herdr-core처럼 답하고, 프로그램 보고를 hc pane이 이미 쓰는 `HookDaemon.applyProgramStatus`로 보낸다.
7501 `idle`이 열린 turn을 닫으면(ESC 취소) WAIT + 알림음 대신 소리 없는 IDLE로 보낸다(hc pane에도 적용).

**Spec:** 별도 spec 문서 없음. 근거는 아래 "확인한 사실"(2026-11-07 실측)과 사용자 결정(D1: IDLE·소리 없음, D2: 지금 구현).
상태 규칙의 기존 근거는 `docs/superpowers/specs/2026-11-01-herdr-core-backend-design.md` §4·§6.6.

## 확인한 사실 (Claude Code 2.1.319, python pty로 실측)

- Claude는 시작할 때 `ESC ] 7501 ; ? BEL`을 보낸다(DA1과 함께, 몇 번 반복). 터미널이 답하지 않으면 7501 보고를 전혀 하지 않는다.
  SwiftTerm은 이 OSC를 모르므로 지금 local pane에는 7501이 하나도 오지 않는다.
- herdr-core의 답: `ESC ] 7501 ; ?:states=idle,working,done,blocked,error:kinds=permission,question,auth` + 질의와 같은 종결자.
  이 답을 주면 Claude가 보고를 시작한다.
- 보고 형식: `ESC ] 7501 ; state=working:app=claude-code BEL`. `key=value`를 `:`로 잇는다. `msg`는 **base64**다.
  예: `state=blocked:app=claude-code:kind=permission:msg=YXBwcm92ZSBCYXNoOiB0b3VjaCAvdG1wL3Rlcm15LTc1MDEtcHJvYmUveC50eHQ=`
  (= `approve Bash: touch /tmp/termy-7501-probe/x.txt`). Claude가 끝나면 `state=clear`.
- ESC 취소 → 약 70ms 뒤 `state=idle`. 권한 프롬프트에서 ESC를 눌러도, `CLAUDE_CODE_NO_FLICKER=1`에서도 같다.
  정상 종료는 `done`(spec spike, 2.1.316). ESC에는 Stop hook이 없다.
- hc pane: `hc events`에서 ESC 직후 `status idle` + `turn` 이벤트를 확인했다. termy는 이미 이 경로로 받는다.

## Global Constraints

- **hc pane에서는 7501 질의에 답하지 않는다.** core가 이미 답한다. termy까지 답하면 두 번째 답이 `remoteInput`을 거쳐
  프로그램 입력(Claude 입력창)으로 들어간다. 그래서 OSC handler는 `Pane.startShell`(local 경로)에서만 켠다.
  `Pane.startHc`와 `HcPaneBackend`는 건드리지 않는다.
- 답하는 바이트는 정확히 `"\u{1b}]7501;?:states=idle,working,done,blocked,error:kinds=permission,question,auth\u{07}"`.
- 상태 규칙은 `PaneStateMachine.applyProgramStatus` 한 곳이다. local pane도 hc pane과 같은 함수를 지나야 한다.
- 7501 `idle`이 `turnOpen == true`인 snapshot에 오면: state `.idle`, `needsAttention == false`, `notificationReason == nil`,
  `waitSource == nil`, `turnOpen == false`. `done`의 규칙(WAIT + `.turnEnd`, 알림)은 그대로다.
  turn이 닫혀 있을 때의 `idle`/`done` 규칙(WAIT이면 그대로, 아니면 IDLE)도 그대로다.
- Swift 6 language mode(`SWIFT_VERSION: "6.0"`). 새 파일이 생기면 `xcodegen generate`를 먼저 돌린다(`termy.xcodeproj`는 git에 없다).

  → `** TEST SUCCEEDED **`. 여러 클래스는 `-only-testing`을 반복한다.
- 테스트 host 주의: XCTest host의 유일한 window를 닫거나 해제하면 앱이 종료된다. 뷰 테스트는 window에 붙이지 않는다.

```swift
import Foundation

// OSC 7501 program status(herdr-core가 쓰는 규약). Claude Code는 시작할 때 `ESC ] 7501 ; ? BEL`로 묻고,
// 답한 터미널에만 상태를 보고한다. hc pane은 core가 답하고 events로 받는다. local pane은 TermyTerminalView가
// 이 parser로 직접 답하고 받는다.
// 보고는 `key=value`를 `:`로 이은 꼴이고 `msg`는 base64다(Claude Code 2.1.319에서 확인).

enum ProgramStatusOSC {
    static let code = 7501

    /// herdr-core가 질의에 주는 답과 같은 바이트. 종결자는 Claude의 질의처럼 BEL이다.
    static let probeReply = "\u{1b}]7501;?:states=idle,working,done,blocked,error:kinds=permission,question,auth\u{07}"

    enum Message: Equatable {
        /// `?`: 이 터미널이 보고를 받는지 묻는다.
        case probe
        /// root 레코드 보고. nil은 `state=clear`(프로그램이 보고를 그만뒀다).
        case status(HcStatus?)
        /// termy가 쓰지 않는 것: `id`가 붙은 레코드, `state`가 없는 보고, UTF-8이 아닌 바이트.
        case ignored
    }

    /// `payload`는 SwiftTerm이 OSC handler에 넘기는 값, 곧 `7501;` 뒤의 바이트다.
    static func parse(_ payload: ArraySlice<UInt8>) -> Message {
        guard let text = String(bytes: payload, encoding: .utf8) else { return .ignored }
        if text.hasPrefix("?") { return .probe }
        var fields: [String: String] = [:]
        for part in text.split(separator: ":") {
            guard let eq = part.firstIndex(of: "=") else { continue }
            fields[String(part[..<eq])] = String(part[part.index(after: eq)...])
        }
        if let id = fields["id"], !id.isEmpty { return .ignored }
        guard let state = fields["state"], !state.isEmpty else { return .ignored }
        if state == "clear" { return .status(nil) }
        let msg = fields["msg"]
            .flatMap { Data(base64Encoded: $0) }
            .flatMap { String(data: $0, encoding: .utf8) }
        return .status(HcStatus(state: state, kind: fields["kind"], msg: msg, app: fields["app"]))
    }
}
```

SwiftTerm 1.20(fork)은 `terminal.registerOscHandler(code: Int, handler: @escaping (ArraySlice<UInt8>) -> ())`를 제공한다.
등록된 handler는 내장 처리보다 먼저 불리고, `data`는 `7501;` 뒤의 바이트다(`EscapeSequenceParser.dispatchOsc`).
답은 `terminal.sendResponse(text:)`로 보낸다. 이것은 `TerminalView.send(source:data:)`를 거치므로 local pane에서는
PTY로, `remoteInput`이 있으면 그쪽으로 간다(테스트는 `remoteInput`으로 보낸 바이트를 잡는다).
